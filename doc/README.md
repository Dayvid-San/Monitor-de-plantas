# Monitor de Plantas — Documentação

Bem-vindo(a)! Esta é a documentação para quem vai **usar, montar ou instalar** o
Monitor de Plantas — não é preciso saber programar para seguir estas páginas.

> Procurando a documentação técnica (para quem vai mexer no código)? Veja o
> [`README.md`](../README.md) na raiz do projeto.

## Comece por aqui

Siga esta ordem se é a primeira vez que você vê o projeto:

1. **[Visão geral](visao-geral.md)** — o que o sistema faz e como as peças se encaixam.
2. **[Lista de compras](lista-de-compras.md)** — o que comprar antes de montar.
3. **[Instalação](instalacao.md)** — passo a passo: backend, firmware e cadastro das plantas.
4. **[Usando o dashboard](usando-o-dashboard.md)** — o dia a dia: acompanhar as plantas, regar manualmente, notificações.

Quando algo não sair como esperado:

- **[Solução de problemas](solucao-de-problemas.md)** — os problemas mais comuns e como resolver.
- **[Perguntas frequentes](perguntas-frequentes.md)** — dúvidas gerais sobre o que o sistema faz e não faz.
